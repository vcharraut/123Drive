# py123d-docker notes

This repo uses `py123d-docker` as the supported extraction entrypoint.

Use the root `README.md` for the current release flow.

Quick examples:

```bash
# List supported datasets
uv run py123d-docker --list

# Convert one dataset
uv run py123d-docker --dataset nuplan-mini --data_root /data --output /data/py123d

# Select splits and workers
uv run py123d-docker --dataset nuplan --data_root /data --output /data/py123d \
  --splits nuplan_train nuplan_val --workers 16
```

Older direct py123d CLI notes are intentionally out of the release path to keep usage minimal.
